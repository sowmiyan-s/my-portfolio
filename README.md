## 🛠️ Tech Stack
This portfolio is built using modern web technologies to ensure a fast, accessible, and SEO-optimized experience:
- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Backend & Database**: Supabase, Edge Functions (Deno)
- **AI & Integrations**: MCP (Model Context Protocol), Open AI / LLM Tooling
- **Deployment**: Vercel

## 📈 SEO & AI Discoverability
This portfolio is heavily optimized for both traditional Search Engines and AI Web Scrapers:
- **Semantic HTML & Meta Tags**: Extensive Open Graph and Twitter Card implementations.
- **JSON-LD Structured Data**: Uses `Person`, `WebSite`, and `ProfilePage` schemas to provide explicit entity context to Google and LLM crawlers.
- **Geo-Targeting**: Explicitly targeted for India (IN) and Tamil Nadu (TN) regions to dominate local search queries.
